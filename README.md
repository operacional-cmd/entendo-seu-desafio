# Entendo o seu desafio — Lean Optimus

Diagnóstico interativo em três etapas, com logo oficial, campos condicionais e seleção de múltiplos desafios.

## Publicação

Site estático, sem dependências e sem etapa de compilação. Na Vercel, usar o preset **Other**, a raiz do repositório e o diretório de saída `.`.

A configuração em `vercel.json` publica o formulário em `/entendo-o-seu-desafio` e redireciona a página inicial para esse caminho.

## Respostas

Esta versão é uma prévia interativa. As respostas ficam somente na memória da página, sem envio, banco de dados ou persistência. Atualizar ou fechar a página apaga as respostas.
